# Для моей Лапули

Личная интерактивная открытка на Next.js, TypeScript и Motion.

## Запуск

`npm install`, затем `npm run dev`. Открыть http://localhost:3000.

`npm run build` — production build; `npm start` — production сервер.

## Изменить открытку

Все тексты, подписи и пути фотографий: `src/content/love.ts`.
Ваши исходные материалы сохранены в `photo`; копии для сайта находятся в `public/photos/photo-1.jpg` … `photo-6.jpg`.
Для добавления фотографии положите её в `public/photos` и добавьте запись в `photos` в файле контента.

Музыка необязательна: положите свой файл в `public/music.mp3`, перезапустите сервер и обновите страницу. Звук начинается только после открытия открытки; кнопка внизу справа отключает его. Если файла нет, сайт открывается без запросов к отсутствующему аудио.

Просмотр фотографий: нажатие, свайп, стрелки клавиатуры; Escape закрывает просмотр. Системная настройка уменьшения движения отключает параллакс и заменяет длинную секцию со сменой фраз статичным списком.

Шрифты хранятся локально в public/fonts и работают без Google Fonts. Поисковая индексация запрещена через metadata.

## Приватный вход

На Vercel добавьте `LOVE_PASSWORD` в Project → Settings → Environment Variables для Production (и Preview, если используете preview-ссылки). После добавления или изменения переменной нужен новый deployment / Redeploy.

Локально создайте `.env.local` по примеру `.env.example`, укажите собственный пароль и перезапустите сервер. `.env.local` и другие реальные env-файлы исключены из Git. Без LOVE_PASSWORD открытка остаётся закрытой.

Пароль проверяется только на сервере. Подписанная cookie `love_access` действует 30 дней, имеет HttpOnly, SameSite=Lax и Secure в production. После смены LOVE_PASSWORD предыдущие cookie перестают подходить.

Личные тексты передаются браузеру только после авторизации. Фотографии, музыка и оптимизатор изображений также закрыты серверной проверкой; приватные ответы запрещено кэшировать. Пароль не попадает в клиентские bundles, localStorage или логи приложения.

## Проверка

`npm run lint`, `npm run typecheck`, `npm run build`.

`npm run verify` — проверка полного сценария на 13 размерах экрана. По умолчанию используется localhost:3000; другой адрес задаётся переменной BASE_URL. Для проверки самой открытки задайте LOVE_PASSWORD в окружении теста с тем же значением, что у сервера.

`node scripts/verify-polish.mjs` — проверка всех фраз, границ текста, свайпов, фокуса, анимации конверта, шрифтов и звука. Для проверки звука запускается временный сервер на порту 3003; если своей музыки нет, временный тихий аудиофайл автоматически удаляется после проверки.

`npm run verify:access` — проверка серверного входа, приватных файлов, cookie, адаптивности формы и перехода к существующей открытке. Тест сам запускает временный production-сервер на порту 3004 со случайным тестовым паролем; пароль не записывается на диск и не выводится в лог.
